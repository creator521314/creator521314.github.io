Arctic Ink

为什么这么做

动手前先给系统做了一次只读体检，四个判断决定了后面的取舍。

  • 换 GTK 主题的收益比想象中低。 GNOME 51 上多数应用是 libadwaita，它们不读 gtk-theme， 只跟随深浅色和 accent-color。所以主角是强调色、图标、光标、字体和壁纸， GTK 主题只用来把旧的 GTK3 程序拉回同一套视觉。
  • 最影响观感的，是中文字体缺失。 系统里唯一的中文字体是等宽的 Maple Mono CN，界面上的中文一直在用代码字体的节奏排版。 补一套思源黑体，比换任何主题的收益都大。
  • 壁纸和强调色要同源。 自绘的渐变壁纸取 #2EC6B0，再把 GNOME 的 accent 设成 teal， 开关、选中态和桌面就属于同一种冷调。
  • 软件美化给不了「顺滑」。 2K 屏当时只跑 59.95 Hz，这是线材或显示器设置的问题； Dock 动效和拖窗口的手感，得去显示器设置里解决。

怎么搭

四层结构，从「有质感」铺到「有氛围」。

层内容
基础 prefer-dark + 青绿 accent；Papirus-Dark 图标（文件夹配色 teal）； Bibata-Modern-Ice 光标；adw-gtk3-dark 收拢旧 GTK3 应用
字体 界面 Inter 11；标题 Inter Bold；等宽 Maple Mono CN；中文回退 Noto Sans CJK SC； 灰度抗锯齿 + 轻微 hinting
桌面 Dash to Dock 底部悬浮、智能隐藏；Blur my Shell 给面板和概览上毛玻璃； AppIndicator 管托盘；Just Perfection 做细节微调
氛围 自绘 arctic-ink 壁纸（附浅色版 arctic-mist）；窗口按钮改为最小化 / 最大化 / 关闭； 24 小时制；关闭热角

配色

深底、低饱和，靠明度而不是描边来分层。

  • #0E1A24底色 / 壁纸暗部
  • #16242F浮层 / 卡片 / 面板
  • #2EC6B0强调色 accent = teal
  • #7AA2F7辅助 / 选中 / 链接
  • #E6EDF3主文字 / 高对比
  • #93A4B4次级文字 / 说明

壁纸

两张 2560×1440 的自绘渐变：深色主用，浅色备用。

用起来

体检、安装、应用、回滚，都收在同一个入口里。

./install.sh doctor      # 只读体检
./install.sh all         # 安装 + 应用
./install.sh rollback    # 恢复到安装前

想先看会改什么：./install.sh all --dry-run；不需要扩展：--no-extensions。 首次安装前会自动备份 dconf 与扩展清单，之后重复执行不会覆盖这份备份。

踩过的坑

  • GNOME 51 刚发布，第三方 Shell 主题（比如 Colloid）的 CSS 未必对得上， 可能出现顶栏高度异常。默认方案不装，想要时再加 --with-shell-theme。
  • Wayland 下不能重启 Shell，新装的扩展必须注销重登才会生效。
  • noto-fonts-cjk 约 300 MB，是这套方案里最大的一笔体积开销。
  • 备份只做第一次：反复 apply 不会覆盖 backup/latest.dconf， 回滚点始终停在「安装前」的那一刻。
